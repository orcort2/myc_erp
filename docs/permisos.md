# Permisos ERP MYC

## Patron

Cada modulo debe seguir este patron:

- `modulo.ver`
- `modulo.crear`
- `modulo.editar`
- `modulo.cancelar`
- `modulo.aprobar`
- `modulo.exportar`
- `modulo.administrar`
